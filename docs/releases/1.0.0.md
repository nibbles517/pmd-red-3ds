The first release of pmd-red-3ds: *Pokémon Mystery Dungeon: Red Rescue Team*, from
[pret/pmd-red](https://github.com/pret/pmd-red)'s decompilation, running natively on
the 3DS.

**No game data is included.** Put your own ROM of *Red Rescue Team* (**USA**), named
`pmdred.gba`, next to `pmd-red-3ds.3dsx` or in `SD:/3ds/pmd-red-3ds/`, and start it
from the Homebrew Launcher. See the [README](README.md) for setup, features,
performance and known bugs.
